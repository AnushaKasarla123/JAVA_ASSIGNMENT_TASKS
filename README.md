# Java Conditional Statements Project

## 📌 Project Overview
This project demonstrates the use of Java conditional statements such as `if`, `if-else`, and `else-if` to evaluate a student's marks, assign grades, determine pass/fail status, and check scholarship eligibility.

## 🎯 Objective
- Practice Java conditional statements.
- Improve logical thinking and decision-making using `if-else`.
- Learn to accept user input using the `Scanner` class.

## 🛠️ Technologies Used
- Java
- VS Code 
- JDK 17 or above

## 📂 Project Structure

```
core-java/
│── conditional_statements.java
│── README.md
```

## 🚀 Features
- Accepts student name and marks as input.
- Validates the entered marks.
- Calculates the student's grade.
- Displays Pass/Fail result.
- Checks scholarship eligibility.

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/AnushaKasarla123/java-conditional-statements.git
   ```

2. Navigate to the project folder:
   ```bash
   cd java-conditional-statements
   ```

3. Compile the program:
   ```bash
   javac conditional_statements.java
   ```

4. Run the program:
   ```bash
   java conditional_statements
   ```
